| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-05-02 | Denial of Service | startupProbe too short → CrashLoop | mitigate | startupProbe failureThreshold 24 periodSeconds 5 (120s budget) per RESEARCH Pattern 5 |
| T-05-03 | Denial of Service | TORCH_NUM_THREADS mismatch | mitigate | ConfigMap TORCH_NUM_THREADS=2 matches limits.cpu 2 (D-15, PERF-04) |

| T-05-SC | Tampering | Helm chart dependency install | accept | No new pip/npm packages; app-only chart has no external chart deps in this plan |
