Output: Runnable FastAPI app, requirements pins, pytest suite with upload + health coverage.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → POST /predict (upload) | Untrusted multipart file bytes cross into server process |
| Client → GET /health/* | Untrusted HTTP requests (low risk, no body) |
| PIL decode | Untrusted image bytes expanded in memory — decompression bomb risk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | POST /predict upload | mitigate | Decode via Pillow only; catch UnidentifiedImageError (mapped in plan 02); keep MAX_IMAGE_PIXELS default |
| T-01-02 | Denial of Service | inference.py | mitigate | max_upload_bytes enforced before full read in plan 02; Pillow pixel limit retained |
| T-01-03 | Information Disclosure | error responses | mitigate | No stack traces to client; generic messages (full ErrorDetail in plan 02) |
| T-01-04 | Tampering | requirements.txt pip install | mitigate | Use pinned versions from STACK.md; Package Legitimacy Audit in RESEARCH.md — all approved |
| T-01-SC | Tampering | pip package installs | mitigate | RESEARCH.md Package Legitimacy Audit completed; pins from official PyPI packages only |
</threat_model>
