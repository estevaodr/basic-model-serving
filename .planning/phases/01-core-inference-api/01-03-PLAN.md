<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → GET /metrics | Unauthenticated metric scrape — public by design for portfolio demo |
| Logs | Request metadata written to stdout — must not include image bytes or URLs with secrets |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-10 | Information Disclosure | JSON logs | mitigate | Log request path/method/status only; never log full image_url query params with credentials or raw image bytes |
| T-01-11 | Denial of Service | metric labels | mitigate | Never label metrics with raw image_url or class names; low-cardinality labels only per RESEARCH Security Domain |
| T-01-12 | Information Disclosure | /metrics | accept | Public /metrics by design — no auth in Phase 1 per PROJECT.md; no secrets in metric labels |
| T-01-13 | Repudiation | request logs | mitigate | request_id on every request for correlation per API-08 |
</threat_model>
