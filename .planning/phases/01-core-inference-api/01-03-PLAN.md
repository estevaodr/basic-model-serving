## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → POST /predict (JSON image_url) | Untrusted URL string triggers server-side outbound HTTP — SSRF boundary |
| Server → external URL | Outbound GET crosses network trust boundary |
| Client → POST /predict (upload) | Untrusted file content |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-01-06 | Tampering | url_fetch outbound | accept | DNS-rebinding residual risk documented; stdlib checks meet portfolio API-05 minimum per RESEARCH Assumption A3 |
| T-01-07 | Denial of Service | url_fetch.py | mitigate | max_bytes stream cap; url_timeout; reject oversized before decode |
| T-01-08 | Information Disclosure | predict error handler | mitigate | ErrorDetail with safe messages; log exceptions server-side only |
| T-01-09 | Tampering | upload path | mitigate | Pillow decode verification; size cap; no disk write of uploads |
</threat_model>
